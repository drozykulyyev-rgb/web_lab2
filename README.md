# ЛР №2, вариант 7745196

## Запуск

Нужен JDK 17 или новее. В PowerShell из папки проекта:

```powershell
.\build.ps1
java -jar build/lab2.jar --http 8080
```

Открой http://127.0.0.1:8080/ . Остановка — Ctrl+C.
Если JAR уже собран и изменены только HTML, CSS или JS, сборка не нужна.
После изменения Java сначала останови сервер (Ctrl+C), затем повтори сборку и запуск.
Запущенный сервер может блокировать перезапись JAR в Windows.
При открытии HTML двойным щелчком запросы к Java работать не будут.

## Как объяснить страницу

1. Пользователь выбирает X и R, вводит Y.
2. Обработчик submit отменяет перезагрузку через preventDefault().
3. JavaScript проверяет: выбран X, число Y строго между −3 и 5, R от 1 до 5.
4. URLSearchParams собирает параметры, например x=1&y=0.5&r=2.
5. sendRequest() отправляет GET-запрос через fetch. Это AJAX: ответ приходит без перезагрузки.
6. Java повторно проверяет данные, вычисляет попадание и возвращает JSON с историей.
7. showHistory() заполняет таблицу, draw() рисует область и точки.

async/await позволяет дождаться ответа. try/catch показывает ошибку запроса,
а finally снова включает кнопки. Форма отключается на время запроса, чтобы не отправлять её дважды.

В draw() начало координат переносится в центр canvas через translate().
Одна единица равна 40 пикселям. Y рисуется со знаком минус:
на canvas координата растёт вниз, а на графике — вверх.

Y отправляется и возвращается строкой, чтобы длинные дроби не округлялись.
В validY() проверяются формат, длина и целая часть: у положительного числа она меньше 5,
у отрицательного — меньше 3. Так проверяется диапазон −3 < Y < 5 без округления дроби.
Java считает попадание через BigDecimal и возвращает hits — пять результатов для R от 1 до 5.
При смене R цвет точки берётся из hits[R − 1]. В Number координата Y переводится только для рисования.
points хранит всю историю для таблицы, graphPoints — только новые точки для графика.
После новой проверки старые точки с графика убираются. При загрузке страницы показывается последняя точка истории.
Таблица хранит результаты сервера при исходном R.
toLocaleString() выводит дату по локали и часовому поясу устройства.

## Условия попадания

Достаточно одного из трёх условий. Границы входят в область.

- Прямоугольник: 0 ≤ x ≤ R и 0 ≤ y ≤ R/2.
- Четверть круга: x ≤ 0, y ≥ 0, x² + y² ≤ R².
- Треугольник: x ≤ 0, y ≤ 0, 2y ≥ −x − R.

История сейчас хранится в памяти Java отдельно для каждого cookie браузера.
Перезагрузка страницы сохраняет историю, перезапуск Java её очищает.
LocalStorage пока не реализован.

## Для Helios

Полная инструкция находится в [HELIOS.md](HELIOS.md).
После загрузки проекта в конечную папку на Helios выполни:

```sh
sh helios.sh setup 24890 24891
sh helios.sh start
sh helios.sh status
```

24890 и 24891 — порты текущего размещения под пользователем s511489.
Пользователь и путь определяются автоматически. Полная конфигурация Apache —
`config/httpd-helios.conf`. Режим `--http` нужен только для локальной отладки.
На Helios связка Apache и Java проверяется скриптом при запуске.
